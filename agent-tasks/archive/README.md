# Historical documentation archive

This directory preserves completed and superseded project-process evidence.

## Important

**Do not use this directory as ordinary implementation context.**

The current agent should normally read:

- root `AGENTS.md`;
- the exact active assignment/manifest;
- `agent-tasks/common/v7.md`;
- relevant source/tests.

Open archive files only when:

- an assignment explicitly cites historical evidence;
- investigating a regression introduced by an old stage;
- verifying an exact old protocol/assignment/review;
- auditing why a product/architecture decision was made.

## Contents

- `common/` — historical protocol generations and superseded process drafts.
- `assignments/` — completed/superseded assignments.
- `reviews/` — completed review records.
- `batches/` — completed historical batch manifests/results.
- `designs/` — resolved design/decision documents.
- `snapshots/` — full pre-compaction copies of formerly oversized root/process documentation.

Git history remains the ultimate immutable source for exact commit-time context.
